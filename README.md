# Service Logos

This repository stores and manages service and software logos for use within Stabilise applications. The logos are dynamically referenced in dashboards, integrations, and other tools to provide a consistent and up-to-date visual representation of third-party vendors.

All logos are stored in the root directory in PNG format with transparent backgrounds. Filenames are lowercase, kebab-case, and should clearly identify the service (e.g., `apple.webp`, `google-workspace.webp`, `cloudflare.webp`). To reference a logo, use the raw GitHub content URL. For example, a logo can be accessed at `https://github.com/Stabilise/Service-Logos/blob/cec29cb3e62f899c318f894db1b1bbcf10eecf47/logos/adobe-creative-cloud.webp`.

When adding a new logo, please ensure it is a high-quality PNG with a transparent background, ideally optimised for web use. Submit a pull request for any additions or changes.
